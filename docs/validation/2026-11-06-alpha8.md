# alpha8：音频连续性、静噪和结果列表

版本 `0.8.0-hfplus-alpha8` / versionCode 9，独立包名不变。保留 alpha7 的 BW 拖柄和全宽显示。

## 音频问题与修复

此前的短样本解调测试没有覆盖持续播放时的 USB 突发供给和 AudioTrack 调度。
这轮补上完整链路验证，并修复以下具体问题：

- PCM 队列原为 8 个任意大小的数据块。HF+ 的 4096 样本回调在 912 kS/s 下约 4.49 ms，8 块实际只有约 36 ms 余量；USB/线程的短时抖动可能令队列丢弃旧块，直接删去一小段音频。
  现在先合并为固定 20 ms 双声道 PCM 包，32 包提供 640 ms 队列预算，保持顺序和左右声道。
- AudioTrack 原本空缓冲即开始计时。现在先填充 80 ms，再播放；硬件缓冲下限为 160 ms，PCM 写入在独立 IO 协程进行。
  这是有限的启动延迟，用于提供实际抖动余量。队列上限不代表每次都会积累到该延迟。
- 相同解调模式的重复指令原本仍会重新创建解调器，重置滤波/鉴频历史。现在相同模式直接保持状态；真正切换模式或音频采样率才清理旧包。
- HF+ IQ 缓冲从 16 块提高到 128 块，保留序号缺口及驱动丢样诊断。
- 音频热路径读取计数器时不再复制整套诊断快照或计算整套 USB 统计；FFT 保持连续输入历史，分析计算限制在约 60 次/秒以内，显示任务减少争抢音频处理时间。
- 恢复已保存音量到新 AudioTrack；避免音频采样率设置后又在 start 中重复创建 AudioTrack。

极端积压仍有有限容量上限，超限会计入诊断。本轮没有把所有可能的实收杂声归结为同一个原因。

## SQL、ETM 与瀑布

- **RF / Audio → SQL**：恢复此前误隐藏的静噪滑条，并重新接入监听门限。
  −120 dB 档显示 Off；其他门限使用 3 dB 迟滞、200 ms 关闭保持及 10 ms 音量渐变，防止门限附近快速开关切碎语音。
  数字解码/原始音频订阅不经过该静噪。OPEN/CLOSED 保持接收机启停功能。
- **ETM / Range**：使用共享结果列表组件。内部能继续滚动时保留纵向手势，到边界后让外层滚动；横向手势让给模块切换，抬手或取消时解除拦截。
- **Waterfall**：默认 FFT 从 256 提高到 2048 点；旧的 256/512 设置一次性迁移，更高的自定义设置保留。相同显示跨度下频率栅格精细 8 倍，可在 Display 再选择 4096/8192。
  同时关闭相邻时间行的位图平滑，避免时间上的模糊。没有把插值像素当作新增射频细节。

## 验证结果

设备为小米 M2007J1SC、Android 13、arm64 / 4 KB 页；通过 USB ADB 覆盖安装，保留用户数据。

- **39 项主机测试通过，0 失败 / 0 跳过**。新增任意 PCM 分块顺序、SQL 迟滞/保持/渐变以及 FFT 分析节流测试。
- **12 项真机测试通过**：完整突发音频三项、原生 FM 两项、显示/能力/机场数据五项、AM TCP 全链路一项、SQL 与长列表手势一项。

完整音频测试模拟 912 kS/s HF+ 浮点 IQ，以每组 16 个 4096 样本回调、约每 72 ms 突发供给，持续 4 秒。
数据经过 DSP、真实 AudioTrack 与 WAV 录音，中间重复发送相同解调模式指令，验证不会重置音频历史。
测试时通过应用自身音量将扬声器静音；不修改手机系统音量。

| 监听链路 | 录音帧数 | 正弦拟合相对 RMS 残差 | IQ 丢块 | PCM 丢包 | 稳定阶段播放欠载 |
| --- | ---: | ---: | ---: | ---: | ---: |
| WFM / 48 kHz | 192000 | 0.000881 | 0 | 0 | 0 |
| WFM / 44.1 kHz | 176400 | 0.000815 | 0 | 0 | 0 |
| WFM Stereo / 44.1 kHz，单声道回退输入 | 176400 | 0.000815 | 0 | 0 | 0 |

帧数符合完整 4 秒音频。相位拟合用于发现删样/短缺口导致的相位跳变，并非主观听感评分。
Stereo 独立声道分离仍由既有原生立体声 IQ 测试验证。
SQL/列表仪器测试用 200 项合成结果，检查内层滚动捕获及顶部边界交还外层；没有改写实际 ETM 暂存台表。
AM TCP 测试确认静噪/手动静音期间解码基带继续产生。

日志：`alpha8-final-build.log`、`alpha8-device-audio.txt`、`alpha8-controls-audio.txt`；
完整音频指标保存在随包的 `burst-audio-*.json`。APK 16 KB ZIP 对齐通过，原生库没有改动，沿用已验证的 16 KB ELF 对齐。

## 仍待实收验证

本轮手机通过 USB 连接电脑，未同时接 HF+。突发测试覆盖真实播放硬件，但 IQ 来自已知样本，不能替代 HF+ USB 驱动、天线和实际信号环境。
仍需实收复听 FM / AM / SSB，分别检查 NR/NB 开关、驱动丢样、长时间欠载与设备温度；本轮未宣称完成 30 分钟持续接收、慢帧率目标或 Android 16 真机验收。
