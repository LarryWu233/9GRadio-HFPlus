# alpha7：BW 边界拖动与 HF+ 全宽频谱

版本 `0.7.0-hfplus-alpha7` / 8，独立包名不变。

## 问题和修复

1. 实机保存了 `FFT Decimation=64`、`Zoom=1.0`，频谱被裁到 IQ 采样跨度的 1/64，但界面显示 1x。
   Zoom 现在合并 FFT 抽取与绘制放大，范围 1–2048 倍；Full 将两者同时恢复为 1，并同步两个设置存储，避免返回设置页后又恢复旧裁窄值。
   工具条改为实际 Span 数值，支持当前接收源的完整 IQ 跨度，频谱与瀑布共用同一窗口。
2. 图表拖动过去直接按当前 Step 取整。以 1 MHz 步进拖动只有数百 kHz 宽的图，容易完全不响应或突然跳动。
   现在图表手势的量化不粗于当前可见范围约百分之一的十进制档位；显式小步进继续保留。顶部加减及 Tune 的 Step 选择不因此改变。
3. 频谱通带左右边界加入可见拖柄和触摸命中区。拖动边界只改变 BW，显示高亮、Tune 滑条和数值同步；单边带只操作外侧边界。
   通带窄到两个触摸区域重叠时不抢占调谐手势，可放大后调整。触感沿用系统振动设置。
4. WFM 之前固定较窄的处理中频，旧上限使 HF+ 无法选用较宽的手动滤波。
   现在手动 BW 会选择足够宽的实际复数中频与滤波器；HF+ 上限为 min(660 kHz, 0.9 × 当前采样率)。Auto 保持广播 200 kHz 默认值，并受实际输入限制。
   RTL / TCP 依据当前采样率限制。其他解调保留其适用的通带范围；没有将 CW、SSB 或数字协议一概扩大到 660 kHz。
5. HF+ 采样率恢复不再经过 RTL 的采样率禁区修正。离线使用上次设备报告的采样率列表；连接时重新读取设备实际能力。
   同时修正模式标签从旧 DSP 状态读取而显示 NFM 的问题，标签跟随当前选择。
6. 快捷 Min / Max 可分别选择 Spectrum / Waterfall，显示电平各自保存；复杂设置保留中文，简单术语用英文。

HF+ 官方规格是 **768 kS/s IQ 下最高 660 kHz 无混叠/镜像有效输出**，并不意味着整个 IQ 采样跨度都是同等性能的有效通带。
来源：[Airspy HF+ Discovery specifications](https://airspy.com/airspy-hf-discovery/)。
当前设备历史报告的 912 kS/s 会作为实际 IQ 跨度显示；不据此宣称其有效射频带宽也达到 912 kHz。

## 验证

- 主机测试 35 项通过，0 失败、0 跳过。
- 新增全宽缩放组合与粗 Step 图表拖动测试；检查 768/912 kS/s 下 660 kHz 请求具有足够的复数处理中频。
- 合成 280 kHz 偏移 IQ：660 kHz 滤波放行，200 kHz 滤波抑制，证明不是只修改 UI 上限。
- 同一 912 kS/s、1 kHz 调制、60 kHz 频偏样本，FM / WFM 在 200 / 660 kHz BW 下各输出 24,000 个 48 kHz 音频样本；稳定段无周期性 RMS 缺口。200 kHz BW 使用 228 kS/s IF；660 kHz BW 使用 912 kS/s IF。
- 小米 Android 13 真机：7 项原生 FM / 显示 / 设备能力 / 机场数据测试通过。
- 新增 1 项真机界面回归通过：设置旧 x64 抽取后 Full 返回 768 kHz 显示；左右边界分别拉到 660 kHz 再收回 200 kHz，频率不变；1 MHz Step 下图表仍能进行较小范围拖动。
- 覆盖安装 versionCode 8，保留测试版数据。APK 16 KB ZIP 对齐检查通过；本轮未改原生库，6 个库沿用此前已检查的 16 KB ELF 对齐。

日志：`alpha7-final-build.log`、`alpha7-device-dsp.txt`、`alpha7-bandwidth-ui.txt`、主机测试 XML。

## 验证边界

本轮手机通过 USB 连接电脑，未接 HF+ 实收。宽带滤波、音频连续性和手势使用确定性样本/设备能力模拟验证。
仍需无线 ADB + HF+ 实收复核 USB 吞吐、660 kHz 手动宽通带下的 CPU/音频欠载及真实信号接收。
没有宣称本轮完成 30 分钟持续接收、慢帧率目标或 Android 16 / 16 KB 真机验收。
