# alpha10：实收时钟、瀑布细节与直接控制

`0.10.0-hfplus-alpha10`，versionCode 11，包名 `com.radiosport.ninegradio.hfplus`。基于公开源码 `002c355` 的衍生测试版，与官方版并存。通过无线 ADB 更新小米 M2007J1SC（Android 13）。

## 本轮变化

- HF+ 先读取并应用设备保存的采样率，再启动采样与 DSP。首次无历史设置时继续使用驱动优先的 768 kS/s。运行中变更 HF+ 速率复用接收源完整关闭、重开和时钟建立流程。
- 瀑布显示复用 SDR++ `doZoom` 的每像素取峰方式，保留缩小显示时容易被插值漏掉的窄信号；放大时保留各 bin 电平。未更改 FFT、重采样、降噪或解调算法。来源、固定提交及许可见[复用记录](../third-party-reuse.md)。
- “频谱与瀑布”页直接放置频谱/瀑布图选择、自动电平开关、上下限滑条。自动状态和手动上下限各自保存；自动开启时手动滑条置灰。旧手动标记不再覆盖自动开关。
- 配色与布局使用一个深色弹窗，包含频谱配色、瀑布配色、频谱高度和填充不透明度。移除电平弹窗入口和重复的可见控制；点击图表分隔条直达电平页。
- 手动切换信号类型，恢复当前设备上次使用该模式的有效频率。首次使用保留当前频率，超出设备范围的历史频率不执行；HF+ 盲区浏览不覆盖上次有效接收频率。自动解调继续跟随频率，包含自动立体声路径，不回跳历史频率。
- 手动历史恢复优先于地区自动选频；明确打开地区推荐仍可选择推荐频率。
- 修复外部调谐只更新小频率、顶部大数字和图表停留在旧频率的问题。
- 实机测试新增偏好快照恢复，避免测试频率污染用户的设备与模式历史。实收工具新增平台播放时钟和频率观测，属于诊断数据，不替换音频实现。

### 静置复测补充

用户说明测试期间曾有操作，且固定测试中心未准确对准实际信号，峰值靠近通带边缘会造成滤波裁切。此种听感不作为音频软件缺陷依据。

| 条件 | 时长 | 观测速率 | IQ/PCM 丢块 | 播放欠载 / 写入错误 |
|---|---:|---:|---|---|
| WFM，87.8 MHz，912 kS/s，BW 660 kHz，SQL/NR/NB 关闭；逐窗参数未变 | 120.081 s | 约 912007 S/s | 0 / 0 | 0 / 0 |
| Stereo，87.8 MHz，912 kS/s，BW Auto 200 kHz，SQL/NR/NB 关闭；测试进程临时拦截触摸，逐窗参数未变 | 120.001 s | 约 911967 S/s | 0 / 0 | 0 / 0 |

中间另一段 Stereo 记录出现 18 个不同调谐频率（87.8–87.933 MHz），7 次欠载集中于频率变化期间。这段明确标为非静置样本。静置结果说明本轮未复现原先明显的连续性故障；不能把信号居中、解调音质、长期运行与两分钟帧连续性混为同一验收。

触摸拦截仅存在于测试 APK 的测试方法内，结束时移除；没有改变正式 APK 或手机系统触控。临时模式、频率、SQL、自动解调和全部偏好快照已还原。

另以官方驱动独立验证 912/768/456/228 kS/s 及 HF/VHF 调谐，速率匹配。完整接收链 912→768→912→456→768 kS/s 切换后，各 5 秒稳定窗口速率匹配，欠载增量均为 0。最初仅修改启动顺序时，切换速率的测试捕捉到 1 次欠载，随后改为重建接收链并通过复测。

没有集成 Oboe/AAudio、没有自行新增重采样或降噪算法。官方 libairspyhf 继续承担设备采样和校正。更完整的对照过程见[音频诊断记录](../audit/2026-11-06-audio-reference.md)。

## 构建与回归

- 构建 debug APK、Android 测试 APK 通过；JVM 测试 **42 项通过**，无失败、错误或跳过。
- **17 项不同的 Android 实机回归通过**：ReceiverPresentationTest 6、FmContinuityTest 2、BurstAudioContinuityTest 3、ReceiverPowerTest 1、HfReceiverClockTest 1、UnifiedControlsTest 1、MainInteractionTest 1、InlineDisplayControlsTest 1、ModeFrequencyMemoryTest 1。
- 新增检查包括窄载波保留、放大电平、越界空白、顶部与小频率同步、直接电平操作、自动开关及两个图表状态独立、配色单独弹窗、模式历史、盲区不覆盖、首次使用、无效历史、自动模式与 Stereo 历史、设备间隔离。
- 瀑布频率定位、调整高度保留历史、分块边界与环绕、合成 FM 连续性及立体声分离、USB 接收机启停继续通过。
- UI 排版以 Android 真实控件绘制快照复核；快照保存于验证包。测试时停止接收以检查界面，不代表图中信号完成协议实收。
- `zipalign -c -P 16 4` 通过；6 个原生库与 alpha9 逐字节相同，沿用已有 ELF 16 KB 对齐检查。

Android 16、16 KB 页实际运行环境、60 秒帧率目标及 30 分钟连续实收未在本轮完成验收。APRS、ACARS 等缺少实收信号的协议不因界面可用而计为实收成功。
