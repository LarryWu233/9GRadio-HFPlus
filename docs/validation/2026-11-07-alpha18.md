# 9GRadio HF+ alpha18

版本 `0.18.0-hfplus-alpha18` / code 19；基于公开源码 `002c355` 的衍生版，包名 `com.radiosport.ninegradio.hfplus`。

## 功能

| 页面 | 实现 | 音频输入 |
| --- | --- | --- |
| CW / CWR | multimon-ng 摩尔斯文字、自动／固定 WPM、复制、保存和记录表 | 软件内、麦克风、WAV |
| SSTV | Robot36 自动识别及手动制式、图像进度、完整图像自动保存、未完成图像手动保存 | 软件内、麦克风、WAV |
| SAT | 卫星 SSTV；APT 历史音频的原始双通道灰度图像 | 软件内、麦克风、WAV |
| EiBi | 离线 B26 节目表、频率／UTC／语言／文字筛选、点击调谐、官方更新和 CSV 导入 | 节目元数据，不解码音频 |

CW/CWR 共用页面。SSTV、SAT、EiBi 的入口位于 Mode 页；模块可以在设置中排序、隐藏。页签使用稳定 ID，原有 APRS、航空、ADS-B、扫描等 ID 保留。配色、弹窗和边框表格沿用现有体系。

首次软件内 SSTV 预设为 14.230 MHz USB、3 kHz；SAT 为 145.800 MHz NFM、50 kHz。它们分别保存接收频率，不改变普通 USB/NFM 的手动模式历史。麦克风选择不调谐接收机。ISS 预设附活动安排入口，不表示当前正在播出；NOAA-15/18/19 已退役，APT 明确标为历史。

## 音频与生命周期

- 服务拥有解码会话，后台串行工作；DSP 回调只复制原始 PCM 并投递有界队列。队列无法跟上时停止并提示，避免静默丢样后继续拼接。
- 软件内输入在监听 NR／陷波／响度补偿之前取得 48 kHz 单声道音频；解码期间旁路 IQ NB。数字图像信号不经过新增监听降噪。现有播放和录制链路保留。
- 麦克风使用 Robot36 的 AudioRecord 输入实现及 Android 运行时权限，优先未处理音频，否则使用语音识别预设。取音期间临时静音本机监听，停止后恢复，不改用户音量设置；MainActivity 实际停止时释放麦克风。
- 输入和设备切换会释放旧输入、取消旧会话；旧会话结果不能覆盖新会话。CLOSED 状态在旧 DSP 尚未完全退出时也拒绝启动软件内解码。
- CW 与 APT 使用独立原生进程，隔离上游静态状态。SSTV 使用同包 Java 适配器取得实际图像，不将噪声示波滚动区冒充接收图片。
- CW/CWR 的射频链改为 SDR++ 的“VFO 滤波→音调变换→AGC”顺序，并移植其浮点 AGC 内核。沿用原有重采样与 FIR 原语，分级抽取后在独立的 8 kHz 以上 IF 时钟上调节通道宽度，再产生 ±800 Hz 音调；不再把 500 Hz BW 当作 500 Hz 采样率。
- CW 硬件接收采用受设备能力约束的偏移调谐，再用既有 NCO 归正，避免中心载波被 DC 修正抹掉。频谱使用真实硬件中心校正位置，显示频率保持不变。固定频率文件使用记录的采样中心，不向文件源发硬件调谐。
- IQ→AM→CW 测试暴露 AM 启动 DC 过渡会抬高摩尔斯门限。接入 GNU Radio 的短式 DC blocker，D=128、22050 Hz，约 5.76 ms 群延迟；只影响 CW 解码入口。核心来源、提交、许可和框架适配见 [开源记录](../third-party-audio-content.md)。
- WAV 支持上游 PCM 8/16/24/32 位整数及 32/64 位浮点，单／双声道。文件按实际采样率转换；EOF 只使用上游有限缓冲收尾，不在用户取消时伪造完整图像。
- IQ 文件伴随 SigMF 1.2.6 元数据，分别记录实际采样中心和显示频率；录制列表显示用户调谐频率，分享时同时提供原始 IQ 和元数据。回放恢复两者，兼容旧版无元数据记录，避免偏移调谐导致文件频率解释错误。本轮闭环测试为固定频率录制。
- 完整 SSTV 图像自动存入应用 `files/decoded/`；手动保存的部分图像标记“未完成”。APT 保存实际处理行，标记原始图像，不声称已识别卫星、同步成功或完成地理校正。APT 单幅上限为 3000 行。

## EiBi

官方允许第三方集成与分发；内置 CSV 和原始使用说明。B26 数据于 2026-11-07 获取，官网显示修改日期 2026-10-31。

匹配检查 UTC、跨午夜播出的起始日、星期、季节和可解析的有效日期；不定期等特殊日代码保持原文可见。语言选择按代码精确匹配，不和电台名称混为一个字符搜索。列表点击经统一调谐入口；当前设备不支持的频率保持原值。节目表并非实收确认。

官方当前 CSV 索引使用 HTTP；仅为 `eibispace.de` / `www.eibispace.de` 开放明文元数据访问，其他域名仍要求 HTTPS。备用为开源 SkyWave 的 GitHub 每日 HTTPS 镜像，使用 Raw / API 入口，按 UTC 自动选择季节，并在界面标明镜像来源。2026-11-07 核对镜像与官网下载文件 SHA-256 完全一致。所有 TLS 校验保留。

下载设超时和 2 MB 上限；失败保留离线表，更新中阻止重复提交。缓存数据与季节信息使用 Android AtomicFile 一起写入，导入验证通过后才替换。

## 验证

设备：小米 M2007J1SC，Android 13，arm64，4 KB 页；无线 ADB，连接 RTL-SDR Blog V4。

- 80 项主机测试通过：保留原 46 项，新增 EiBi 边界 5 项、CW 路由边界 2 项及 Robot36 上游输入／文件／EOF 测试 27 项。上游会话管理器只作为这些主机测试的依赖，不作为应用实现。
- 真机新功能：页签、SSTV/SAT 预设、CLOSED 拒绝软件内启动、EiBi 点击调谐与精确语言筛选；麦克风真实取音、Activity 转到 CREATED 后停止取音，频率保持不变。测试临时授予的麦克风权限在完成后恢复。
- 真机解码样本 4 项：自动／固定 WPM 的已知文字；Robot36 完整图像及静音不产图；APT 明暗条纹、重复会话；取消竞争与损坏 WAV。均为合成协议样本，不标为实收。
- 完整 IQ 测试 7 项：AM 软件内 CW（监听 NR/NB 开启、解码旁路 IQ NB）；CW/CWR 各自的中心和偏移载波；500 Hz BW 下音调维持 800/700/900 Hz 而非混叠成低频；1.920 MS/s 下存在高 20 dB、偏移 8 kHz 的邻频干扰仍解码成功、保持实时且逐帧计数无损；CW 偏移调谐录制→文件回放再次解出同一文字，频率解释保持一致。
- 本地 CSV 导入及无效导入保留原缓存，真机检查通过。
- 回归：SPAN/BW 直接输入 1 项、地图拖动／缩放 1 项、七套主题与录制定时／静噪门控 2 项；FM 单／立体声 2 项、突发输入播放／录音连续性 4 项。
- 本轮合计 24 项真机检查通过，包含最终版本的界面、录制、声音连续性与解码回归。
- 另有 1 项实时联网刷新未通过：备用机解锁并置于前台后，EiBi HTTP 官网及 GitHub HTTPS 入口仍返回连接提前关闭／握手失败。记录真实失败日志；没有将镜像替代来源、锁屏限制或官网状态猜测当作已确认根因。当前内置 B26 数据及本地导入正常，手机在线更新须待网络可达后复验。
- 全部 8 个原生文件检查 ELF 16 KB 对齐，APK 检查 zipalign；安装件哈希、测试日志与截图随验证包提供。
- 新增一个音频解码进程；原有七个原生文件与 alpha17 字节一致。验证包也包含 80 项主机测试的 JUnit XML。

未完成实收验收：现场 CW、SSTV、卫星图像及外部接收机经麦克风传入的协议解码；这轮验证了手机实际取音及已知 PCM/IQ 样本。Android 16、16 KB 真机、连续 30 分钟和 60 秒帧率指标本轮未验收。当前可用手机和天线不作为卫星活动是否播出的判断依据。
