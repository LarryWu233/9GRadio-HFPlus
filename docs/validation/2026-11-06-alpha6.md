# alpha6：控件统一与广播 FM 音频设置

版本 `0.6.0-hfplus-alpha6` / versionCode 7，独立包名 `com.radiosport.ninegradio.hfplus`。
基于公开源码 `002c355`。本记录包含未单独交付的 alpha5 改动。

## 界面和调谐

- Mode 恢复完整块状选择。ETM / Range、SW / FM 使用全部可见的并列选择器；频段预设按类别筛选列表。
- Tune 保留渐变回中滑条；下方微调滚轮去除数字；Step 使用相同滚轮，显示可读档位，选择有触感，停止后档位回到中央。
- BW 统一为滑条及 − / Auto / +。Zoom 支持两图按钮、设置滑条与双指缩放。
- 顶部频率每三位以小数点分隔，Hz 位保持弱化；细调仍保留 Hz 精度。
- 简单术语使用 English，详细设置与状态说明使用中文；Scan / ETM、Tune 和其他基础页按钮使用共享样式。深色主题不随系统浅色模式切换，列表选择弹窗和 ACARS 详情使用同一套主题。
- 移除独立 Shutdown 功能，只在设备名称右侧保留 OPEN/CLOSED 接收机开关。
- 面板箭头透明悬浮，随状态翻转；展开保留图表与 Zoom 工具条。去除 AppBar 阴影造成的状态栏色差。
- HF+ 在 31–64 MHz 可连续拖动浏览。显示盲区、清空旧图表，并停止有效音频/解码；保留当前合法硬件中心，不发送越界调谐命令。回到支持范围恢复接收；扫描依然跳过空档。

## WFM Stereo 和 De-emphasis

旧设置存在但未接入 DSP；旧 WFM Stereo 最终播放链路还会将 L/R 再混为单声道。

现在使用连续 FM 鉴频和 19 kHz 导频锁定，恢复 38 kHz 差分载波、左右矩阵及去加重。导频弱时回退单声道；分块保留状态，切换 50/75 μs 不重置整条链路。
Stereo 开关与 WFM / WFM Stereo 模式双向同步；其他解调保持所选模式，切换不改变接收频率。设备配置恢复时也同步该状态。
De-emphasis 改为仅含 50 / 75 μs 的有效选项；旧整数滑条迁移为列表值，旧的中间值统一到原先实际使用的 75 μs。

播放和 WAV 录音使用双声道传输，左右分别重采样和监听 NR/NB；其他单声道模式复制到 L/R，数字解码输入保持独立。
RDS 从原始 FM multiplex 取样，避免从已低通/去加重的监听音频提取 57 kHz 子载波。

## 验证

设备：小米 M2007J1SC，Android 13 / API 33、arm64、4 KB 页。USB ADB 覆盖安装，保留测试版数据；官方版包名不变。

| 检查 | 结果 |
| --- | --- |
| 构建、主机测试、仪器测试 APK 编译 | 通过，30 项主机测试，0 失败 / 0 跳过 |
| 50 / 75 μs 频率响应 | 6 kHz 幅度比符合一阶去加重理论，容差 0.01 |
| 合成 FM stereo multiplex | 主机左右声道分离约 44.94 / 47.14 dB，任意分块连续 |
| 原生 FM / WFM | 912 kS/s IQ、1 kHz 音调、60 kHz 频偏；0.5 秒各输出 24,000 个 48 kHz 样本，稳定段无周期性 RMS 缺口 |
| 真机原生 Stereo IQ → 双声道重采样 | 1 秒输出约 48,000 帧，左右分离均超过 20 dB |
| WAV | 双声道、采样率、字节率、帧对齐、数据长度及 L/R 顺序正确 |
| 真机 DSP / 显示测试 | 8 项通过：原生 FM 两项、AM TCP 全链路一项、显示/设备能力/机场数据五项 |

| 可视检查 | Mode 块状、ETM / Range 并列、微调无数字、Step 档位可读、瀑布与 FFT 二级弹窗深色、状态栏与设备栏同色 |

APK 和所有原生库的 16 KB 对齐检查见随包验证日志；此手机本身为 4 KB 页，不能代表 16 KB 真机运行验收。
