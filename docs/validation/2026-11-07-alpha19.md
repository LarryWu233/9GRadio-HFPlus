# 9GRadio HF+ alpha19

版本 `0.19.0-hfplus-alpha19` / code 20。延续公开源码 `002c355` 的独立衍生版基线。

## 改动

- 解调模式页增加“电台记忆”开关，默认开启以保留既有行为。关闭前保存最后一次开启状态下的频率；关闭期间，模式切换、延迟保存、结束调谐和退出均不改写已有的各模式频率。
- 重新开启时恢复当前模式原有的有效频率，同时更新当前设备／全局状态，避免进程被终止后回到关闭期间的频率。频率不适用于当前接收机时仍沿用原有能力校验。
- ADS-B 不再绕过关闭状态强制跳到 1090 MHz；自动地区调谐同样被阻止。主动选频、收藏、预设仍可调谐，自动解调继续跟随频率。
- SSTV/SAT 内容页遵守同一开关：关闭时进入模块不跳台、不写历史；明确选择频率预设仍可调谐，但关闭期间不覆盖模块的历史。
- 面板箭头上移 6 dp，保留圆钝线条与原有点击／滑动展开方式，颜色跟随主题。
- 菜单采用顶部圆角、轻微高光与真实背景模糊。只模糊顶部 44 dp，文字、图标和正文保持清晰；复用 [BlurView 3.2.0](../third-party-blurview.md)，不自行编写模糊算法。

## 验证

构建、80 项主机测试、APK 签名、zip 对齐与 8 个原生文件的 ELF 16 KB 静态检查分别核对。新增 UI 库不包含原生库，接收与 DSP 原生算法未修改。

本轮 5 项针对性真机检查全部通过；此前 alpha18 的 24 项记录保留为历史验证，不算作本轮全部重跑。真机为 Android 13／4 KB 页的小米备用机，公开安装件已装入手机。

- 电台记忆持久化：关闭前未完成的延迟保存、关闭时改频与切换、退出重建、重新开启恢复、开启后继续记忆。
- 既有手动模式记忆、自动解调跟随及设备隔离回归。
- 新开关、SSTV/SAT 与模拟／数字选择、页面重建、磨砂层硬件绘制、箭头展开／收起。
- 箭头附近标签的真实触控穿透。
- 地图平移／缩放回归：测试需使用支持 ADS-B 的 RTL 配置；地图实际可见后才注入手势。

最初 UI 检查在面板动画结束前判断状态，已调整为等待稳定后检查。地图旧用例最初沿用 HF+ 配置，对隐藏的 ADS-B 页面注入触控，被系统拒绝；随后明确配置与可见性前置条件。没有把这些初次失败当作通过。

原始设备截图、日志和本机连接信息只留在忽略提交的构建目录。Android 16、旧系统模糊兼容路径、16 KB 真机、长期运行与帧率目标仍未完成本轮验收。
