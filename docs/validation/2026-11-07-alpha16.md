# 9GRadio HF+ alpha16

版本 `0.16.0-hfplus-alpha16` / code 17，基于公开源码 `002c355` 的衍生测试版。

## 界面与设置

- 设置从底部 ViewPager 的模块集合中移除；顶部齿轮打开独立设置页面，带返回栏。设备信息、诊断、收藏、模块排序和外观选项在此保留。旧模块排序中的设置 ID 会被忽略，不占用底栏位置。
- 接收机型号后紧跟 OPEN/CLOSED，连接标记分别为绿色和红色。面板箭头下移，展开地图时位于频率读数下方。
- 状态条压到 28 dp，dBFS 单行、小字号；限制模式与采样率文本宽度，避免挤占场强。Tune 的选择顺序调整为 BW、Step。
- 模拟与数字模式各自采用三列表格，保持分组及设备能力限制。飞机、扫描结果和 ETM 暂存台采用同一个带边框、表头和行操作的表格组件，保留详情、点击调谐与扫描排除操作。
- 频谱与瀑布、录制、扫描采用更紧凑的字号、间距和控件；录制的红色语义保留。扫描频道表最多每秒刷新四次，不改变搜索判定算法。

## 补齐录制功能

- 自动停止支持不限时、10 秒、30 秒、1 / 5 / 10 / 30 分钟及 1 小时。IQ 和声音各自计时，依据单调时钟，由接收服务执行，不依赖页面生命周期。计时选项在录制时禁用，结束后恢复。
- “按静噪门限录制”同时控制 IQ 与声音写盘；复用已有 `ListeningSquelch` 的 3 dB 迟滞和 200 ms 保持，录制门控从关闭状态启动。SQL 关闭（−120 dBFS）时连续录制。
- IQ 在任何 NB/解调处理前写入，保持 UC8 / CF32 格式。音频队列携带门控状态与切换代次，在实际写盘时复核，避免队列中的旧状态漏入文件。USB、解码、监听及播放队列继续运行。
- 低于门限的空隙直接省略，文件连接有效片段；不按等待时间填充静音。录制页显示录制／等待信号状态及剩余时间。
- 定时、手动停止和断开接收机均关闭文件、修正 WAV 头，并将实际捕获时长与文件大小更新到记录。改变 IQ 采样率或声音输出率前结束相应录制，防止一个文件混入不同采样率。
- 复用现有 IQ/WAV 写入器与静噪检测，不另写底层 DSP。录制触发行为对照 [SDRangel File Sink 文档](https://github.com/f4exb/sdrangel/blob/master/plugins/channelrx/filesink/readme.md)；未复制其 DSP 内核，也未添加预录、后录或自动分卷能力。

## 验证

当前验证日志与设备截图位于对应 validation ZIP。测试使用小米 M2007J1SC、Android 13，录制测试输入确定性的 AM IQ 样本，并检查关闭门控不写入、开启后写入、定时停止、设置页重建不中断 DSP、WAV 数据长度和 Room 元数据。

- 构建成功，46 项主机单元测试通过。
- 14 个不同的界面／硬件测试项目均有通过记录：批量回归为 12 通过、2 失败；两项失败分别独立复测通过。带宽夹具修正为先退出 ADS-B 再请求 HF+ 采样率；录制／主题在去掉批量前台启动恢复干扰后两项独立通过。原始失败日志保留，不声称原批次全部通过。
- FM 单声道／立体声连续性 2 项、突发输入播放／录音连续性 4 项、原生 readsb 样本解码 1 项，共 7 项通过。突发场景检查队列丢帧、稳定段播放欠载、WAV 帧数及相位连续性；不是 30 分钟实收验证。
- 顶部设置 → 收藏 → 返回主界面选台的 Activity Result 路径通过；未修改用户收藏数据库。
- RTL-SDR V4 的 OPEN/CLOSED、ADS-B 地图／测向面板切换中继续读 IQ、关闭释放解码进程及重开通过。没有以当前实收飞机数量比较性能。
- APK 内七个原生库与 alpha14 字节一致；ELF 16 KB 对齐、APK zipalign 检查通过，手机安装 APK 的 SHA-256 与构建件一致。

Android 16、真实 16 KB 页运行环境、60 秒帧率指标及 30 分钟连续实收不列为本轮已通过项。AIS 与完整测向站等此前缺失的上游能力仍以 alpha14 记录为准。
