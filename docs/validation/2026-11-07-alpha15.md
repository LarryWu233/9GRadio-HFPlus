# 9GRadio HF+ alpha15

版本 `0.15.0-hfplus-alpha15` / code 16；独立包名保持 `com.radiosport.ninegradio.hfplus`。

## 改动

- 将“原版底图连接失败；接收与目标数据继续运行。”改为简短的地图可用状态及已定位目标数；地图源名称使用 OpenStreetMap，不再出现“原版”比较文案。没有更换底图服务。
- 飞机信息改成每架一行的表格，正文 11 sp、表头 10 sp；表头带单位、每格带边框、隔行区分背景。ICAO、呼号、高度、速度、航向、距离排在前面，坐标、升降率和更新时间位于后面；表头与数据一起横向滚动。空值显示“—”，点击整行继续打开飞机详情。
- 主界面模块和已有独立 ADS-B 页面共用同一表格组件。列表保持原来的上下滚动边界处理。

## 验证

构建成功，APK 已通过无线 ADB 安装到小米 Android 13 备用机。全部七个原生库与 alpha14 APK 字节一致，ELF 16 KB 对齐和 APK `zipalign -c -P 16 4` 静态检查通过；本轮修改为界面与文案。

用户恢复网络后，在手机应用内请求原 OSM 瓦片返回 HTTP 200，PNG 文件头有效。ADS-B 和 APRS 的已知位置图层检查通过，真实屏幕截图已显示底图与明确的样本位置标记。此结果仅代表本次手机网络条件，不代表所有大陆网络长期可达；样本标记不作为真实飞机定位验收。

复用既有 2.4 MS/s UC8 IQ 样本，在手机 Android 运行时检查 native 解码结果及表格绑定：两架目标分别显示 ICAO `40621D` / 高度 `38000`、ICAO `4840D6` / 呼号 `KLM1023`。表格绘制快照已核对单行文字、边框、空值及隔行背景；单元格关闭内部文字横滚，避免文字被布局到超大宽度。样本目标不是实收数据，回放结束后清理接收对象。

最终 APK 的地图样本检查与 IQ 回放检查各一项通过。当前真实信号未提供新目标，因此本轮表格的数据填充以样本验证为依据；此前 alpha14 的实收结果仍独立保留，不重复计为本轮实收。没有为本轮界面修改重复运行全部 DSP 测试。

此前接收链与完整功能缺口仍见 [alpha14 验证记录](2026-11-07-alpha14.md)。YouLoop 天线的 1090 MHz 接收条件仍按用户说明记录，不以暂时没有新目标判断软件故障。
