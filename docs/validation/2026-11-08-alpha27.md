# 9GRadio HF+ alpha27

`0.27.0-hfplus-alpha27` / build 28，继续基于公开源码 `002c355`（应用配置 1.39），不等于官方 1.83 完整源码。

## 改动

- 设置根表面色延伸至状态栏，正文容器仍保持主背景；安全区域留白不变，标题与返回不进入刘海。
- 菜单图标选中／未选中分别读取主题 radioAccent／radioSecondary，消除固定青蓝色。
- 图标栏上下圆角和外层上沿统一为 16 dp，较原 28 dp 收敛。45% 色调头部叠在既有模糊上，底部圆角可见；模糊半径和透明度保持。
- 频段名称与范围拆分，中间留白，范围使用 10 sp。宽频段简化到一位小数；窄频段保留必要精度，实际接收和调谐精度不变。模式状态文字背景透明。
- 内容页共享并排按钮行使用 48 dp 高度与 8 dp 间距，覆盖 CW／CWR、SSTV、SAT、EiBi 原动作。
- 无文字原创矢量图标：开放调谐环、信号峰和橙色指示点。更新 Android 8+ 自适应资源，添加 Android 13+ 单色层；未新增位图库或 Compose。

## 验证

构建及 91 项现有主机测试通过。Android 13 小米备用机上完成 2 项针对性用例：

1. 七主题逐一重建并检查背景、设置页和文字对比；实际 TabLayout 的选中和默认图标色均与各皮肤的语义色一致。渲染 APK 自适应图标并验证单色层存在。
2. 既有录音播放器、进度拖动、暂停、长按快进、页内展开／还原、折叠隐藏，以及多种导航栏 inset 的检查通过；展开仍有连续中间位置。

初次图标导出通过 PackageManager 得到小米包装后的 BitmapDrawable，测试辅助代码错误地按 AdaptiveIconDrawable 转型；改为读取 APK 自身 drawable 后通过，没有为此改动主应用。

实机核对当前鼠尾草主题：状态栏与设置工具栏空白区域均为 RGB (32,40,31)；频段范围完整显示 87.5–108.0 MHz。打开 CW 内容页核对按钮，两个间隔均为 22 px，约 8 dp；未启动接收、麦克风解码或录制。本应用偏好在检查前完整快照，结束后逐文件恢复并校验字节一致。另目视确认菜单上下圆角、模式去底块与图标彩色／单色绘制。

截图、原始设备日志及偏好快照不发布。清理本项目测试缓存、测试辅助包和已确认的 distance_test 偏好，不碰用户录音、收藏、地图或其他配置。

APK 签名、zipalign 16 KB、8 个原生文件的 ELF 静态对齐和隐私扫描通过；手机 APK 与发布文件按 SHA256 核对。附件为 arm64-v8a、debug 签名且可调试的 alpha APK、对应源码及校验值。

本轮不改驱动、DSP、解码和录制链路。Android 16／16 KB 实机、小米 15 Pro、完整大字号／横屏矩阵、RF 实收、长期运行和帧率仍待验收；其余边界沿用此前记录。主题图标的桌面呈现取决于系统和启动器支持，提供单色层不等于已验收所有桌面。
