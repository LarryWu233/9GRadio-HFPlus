# 9GRadio HF+ alpha28

`0.28.0-hfplus-alpha28` / build 29，继续基于公开源码 `002c355`（应用配置 1.39），不等于官方 1.83 完整源码。

## 改动

- 将频道预设五等分按钮改为 Material ChipGroup 自动换行：全部、广播、业余、航空、其他完整显示，14 sp 标签，最低 72 dp 宽度及原生触控目标。横向间距 8 dp、行距 4 dp；没有额外横向滚动或缩成省略号。原分类、频率记忆和设备能力判断保持。
- 预设分类与收藏筛选共用 RadioChoiceChips，以主题的容器、强调、次要文字及轮廓色表达状态。收藏仍可横向浏览数量不定的分组；All／Uncategorized 改为全部／未分组。
- 收藏条目固定底色、橙色模式标签和按钮黑字改用相应主题角色。原数据库中单独设置的 color 标记值及其显示保持，不迁移或改写用户分类色。

## 验证

构建及 91 项既有主机测试通过。复用 1 项 Android 13 真机流程，检查快捷收藏编辑、保存、搜索、回选、设置及收藏管理页导航；生成收藏在 finally 清理，原设置恢复。

首次用例被小米“本应用打开自己的测试辅助包”确认窗夺焦阻挡；用户此前已明确授权此辅助包，确认同一提示后重跑通过。没有为此改变主应用。

实际在备用机查看预设弹窗：五项标签完整、分为两行，逐项切换后恢复全部，未选择具体预设调谐。鼠尾草／经典两主题下，收藏筛选文字、选中填充和轮廓正确变化；全部／未分组切换正常。备用机当前收藏列表为空，未为配色截图额外写入用户条目；条目颜色改动按资源和绑定代码核对，收藏数据流程使用上述临时样本验证。完整偏好快照在手动检查后逐文件恢复并核对一致。
