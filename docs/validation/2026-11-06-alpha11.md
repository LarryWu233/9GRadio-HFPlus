# alpha11：监听响度补偿、啸叫抑制与主界面整理

`0.11.0-hfplus-alpha11`，versionCode 12，包名 `com.radiosport.ninegradio.hfplus`。基于公开源码 `002c355` 的衍生测试版。已通过无线 ADB 更新小米 M2007J1SC（Android 13），本次 APK 为 arm64-v8a。

## 改动

- 接收机与音频页新增独立的响度补偿和自动陷波开关，默认关闭。响度补偿复用 SDR++ AGC 包络与增益计算，左右声道使用同一增益；补偿上限 ±3～18 dB，默认 ±12 dB。监听包络参考设为 0.025（约 −32 dBFS），攻击 5 ms、恢复 400 ms。
- 自动陷波直接编译 WDSP ANF 内核，跟踪速度可调，针对持续窄带尖音；CW/CWR/RAW 暂停陷波并显示原因。启停以 20 ms 混合过渡。新处理在静噪及用户音量之前执行，不改变数字解码输入；已解码语音只在监听输出处处理。
- 官方实现、固定提交、许可证和接入修改见[成熟实现复用记录](../third-party-reuse.md)。没有重新编写陷波算法，也没有替换音频后端、FFT 或重采样。
- 移除顶部独立 Step 横条。频谱下方左侧为显示宽度的 − / 数值 / +，点数值恢复全宽；右侧以同样形式调整 Step，并提供振动反馈。Step 按键只改变步进，不改变当前频率；解调 BW 仍可拖动通带边缘或在 Tune 调整。
- 去掉右侧原有 `...` 入口和独立全宽按钮。电平仍直接位于频谱与瀑布页；配色/高度比例在配色与布局弹窗。
- 面板箭头使用钝角、圆端与圆角连接的折线，随展开/收起翻转，背景透明。
- 设备与设置页入口统一为矩形列表；详细设置保留标准选择列表和单选框，使用深色主题。

## 同一录音的陷波对比

用户确认当前 11.92 MHz 附近、AM 模式有持续尖叫。实际调谐值为 **11.916 MHz**，保留该位置，通过原有监听录音功能取得 **19.84 秒、48 kHz、16 位立体声 WAV**。这是应用已有处理后的监听 PCM，不是原始射频 IQ。

将同一文件分别保留原样、通过新陷波处理，AGC 关闭，排除电台和传播条件变化的影响：

| 指标 | 结果 |
|---|---:|
| 窄音调位置 | 约 5001 Hz |
| 该音调相干分量变化（舍弃前 3 秒收敛） | −23.60 dB |
| 4975–5025 Hz 整个频段能量变化 | −6.32 dB |
| 300–3000 Hz 整个频段能量变化 | +0.37 dB |
| 按 300–3000 Hz 能量匹配后的陷波样本增益 | 0.9588 |

窄音调分量与含背景噪声的整段频带是不同指标，不将 −23.60 dB 当作全部噪声降低量。匹配样本已保存用于试听；频带能量接近不能证明人声完全无损，人声可懂度、音乐谐波损伤和不同干扰的听感仍待试听。

## 真机连续接收

HF+、AM 11.916 MHz、912 kS/s、48 kHz 监听、BW 12.5 kHz。保留用户原有 NR/NB 开启状态，再临时同时开启新响度补偿与自动陷波，连续 **60.024 秒**：

- 观测速率约 911883 S/s，平台播放时钟约 47999.8 frames/s。
- IQ 丢块、PCM 队列丢块、播放欠载、写入错误均为 0。
- 592 个观测窗口的频率、采样率、模式、BW、NR/NB 未变化，没有无输入窗口。
- 测试结束恢复原有声音开关与偏好，移除测试触摸拦截，不改变系统设置。

此项检查处理开销与播放连续性；不代替 30 分钟长期验收或接收音质试听。
