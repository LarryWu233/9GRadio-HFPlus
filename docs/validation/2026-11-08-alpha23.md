# 9GRadio HF+ alpha23

`0.23.0-hfplus-alpha23` / code 24，继续基于公开快照 `002c355`（应用配置 1.39），不声称包含官方 1.83 的完整实现。

## 技术栈与改动

检查后确认是 Kotlin、XML、ViewBinding／DataBinding、AppCompat、Material Components **1.12.0**、AndroidX Preference、ViewPager2／BottomSheet 及自定义绘图 View。没有引入 Compose、替换导航架构或重写信号处理。

依据用户提供的 Material 3 skill，使用现有库的 `Theme.Material3.Dark.NoActionBar`、MaterialSwitch 和 Slider。颜色角色映射到原有七套暗色主题；统一圆角、8 dp 间距系统、常用字体层级与启用／禁用状态。设置保持原 Preference 键、状态存储与监听，仅统一行布局、开关 widget、分类和间距；原生 SeekBar 也使用相同轨道／握柄规范。保留原模式网格、数据表、录制红色、地图配色和透明的录音控制图标。

Tune 快速调频复用 Material Slider 与现有依赖链中的 AndroidX DynamicAnimation **1.0.0**：握柄、方向符号、中心至握柄的速度色带。保留原来的速率曲线、细调频率轮、Step 轮和回调。松手／取消／失焦／隐藏／后台立即停止，弹簧仅用于视觉回中；键盘和 TalkBack 为有限步进。细调轮去掉固定蓝色光晕，指针和边缘使用主题 token，不改变刻度、频率读数或手势方向。

规范和来源见 [Material 3 Views 设计规范](../ui/material3-views.md)。本轮生产代码只调整 UI 与资源，驱动、DSP、解码、音频编码器及录制数据格式不改。

## 验证

- 构建通过，**91 项主机测试通过**。
- 对照 alpha22 的 **103 个既有 XML 文件**，原有控件 ID 和 Preference key 没有移除；保留七个主题 ID。该静态核对不能替代所有功能的实收验收。
- 七套主题的 token 对比度计算：强调色对背景最低约 **7.85:1**，正文对高层表面最低约 **6.68:1**，滑条对高层表面最低约 **3.88:1**，关闭开关轮廓对轨道最低约 **3.08:1**。这是指定角色组合的计算，不是对全部频谱色彩或任意叠加画面的认证。
- Android 13 小米备用机、arm64、4 KB 页完成 **9 项针对性自动检查**：

| 检查 | 数量 | 范围 |
| --- | --- | --- |
| 新拨杆 | 1 | 小／大偏移速率关系、左右方向、松手与取消立即停频、回中无额外步进、真实 Home 后台及恢复。 |
| 七套主题 | 1 | 所有暗色方案、正文对比、独立设置页及选择框。 |
| Tune | 1 | SPAN／BW 长按输入、无效值提示与 Step 轮保留。 |
| 地图 | 1 | 原有地图拖动／双指缩放不带动控制面板。 |
| 模式记忆 | 1 | 冻结／恢复、内容页及重建后的状态。 |
| 录音播放器 | 1 | 时长、暂停、拖动、长按快进、页内展开与收起。 |
| 模拟／数字噪声处理控制 | 2 | 模拟设置恢复、数字模式控件关闭及原有 DSP 旁路策略。 |
| 录制与二级设置 | 1 | IQ／WAV 静噪门控、自动停止、设置重建不更换 DSP、最终文件头及元数据。 |

另从实际设置入口核对最终设置行和弹窗，操作“反向调谐”开关并验证写入后恢复原值。没有用截图过程中的过渡帧作为最终透明度或间距结论。手机安装 APK 与发布物逐字节校验，签名、zip 对齐及全部 8 个原生文件的 ELF 16 KB 静态检查通过。

首轮新生命周期检查被 MIUI 的测试辅助启动确认阻挡，没有计作通过；改用系统 Home 与显式桌面入口验证，不依赖该持久授权。测试逐项独立启动应用，避免已有前台实例的测试框架等待。既有录制用例先读到异步收尾期间的初始 WAV 头，现改为等待最终元数据后校验并检查录制错误，最终用例通过；没有为此改动录制实现。

## 边界

这些结果验证已知样本与当前备用机 UI，不等于重新完成 HF+／RTL 的全部实收验收，也不等于完整 M3 无障碍认证。小米 15 Pro、大字号／大屏／横屏的完整矩阵、Android 16、16 KB 实机、60 秒帧率及长期接收／录制目标仍需分别验收。上一轮 EiBi 联网及公开源码完整性限制保持。

原有录音和接收设置保留；临时样本、原始设备截图／日志、独立测试 APK 与本机配置不进入 Release。保留可复现测试源码、第三方来源与双语说明。
