# 9GRadio HF+ alpha26

`0.26.0-hfplus-alpha26` / build 27，继续基于公开源码 `002c355`（应用配置 1.39），不等于官方 1.83 完整源码。

## 改动

- 首页图谱调谐方式旁增加书签按钮，以同主题小弹窗填写备注名称及可编辑 MHz 频率。Tune 频段预设下方增加“我的收藏”，使用一致的入口行和列表弹窗，支持搜索和设备频率能力限制。直接使用原 bookmarks 表，无迁移、无重复收藏库；原分组、标记、管理与导入导出保留。
- 收藏相关星形图标改为空心／实心书签，使用主题色；原 favorite 字段与筛选含义保留。
- 录音声音格式、PCM 位深、码率及参数提示并入设置“录制”分类，使用原 key；保留旧独立 Activity 内部兼容入口。
- 分类标题在 Preference bind 后设置强调色，修正首次进入与滚动回收后的颜色不一致。
- 二级 Activity 使用统一 systemBars／displayCutout 留白，主界面继续保持自己的 inset 规则。
- 地图／录音页展开到频率数字下方时，先调用现有 Material BottomSheetBehavior 的 settling，再进行内容尺寸重排，消除布局抢先跳到终点。没有另写动画引擎。
- 显示图标保留波形与下方两条横线。

## 验证

构建及 91 项既有主机测试通过。Android 13 小米备用机上通过 2 项针对性真机用例：

1. 从首页快捷收藏填写名称、将频率改为 14.230 MHz，保存至原数据库；在“我的收藏”搜索并调谐回该频率。核对声音格式／位深／码率所属 category 为 cat_recording；切换 WAV 后位深显示、码率隐藏。首次设置标题颜色为主题强调色，设置工具栏及收藏搜索框均位于状态栏／刘海下方。测试结束删除唯一命名的收藏并恢复设置。
2. 既有录音播放用例继续验证时长、播放暂停、进度拖动、长按快进、页内展开、返回和折叠隐藏。新增采样断言：系统动画开启时，展开过程有两个以上不同的面板位置，而非一次跳变；最终仍准确停在频率数字下方。生成录音及数据库记录在 finally 清理。

首次收藏用例因搜索框与结果行均包含测试名称，测试匹配器产生歧义；收窄为列表文本项后通过，没有为此修改主应用逻辑。另核对实际快捷收藏弹窗、设置首页与录制分类排版，不保存额外用户内容。原始截图、设备日志和生成样本不发布。

APK 签名、zipalign 16 KB、8 个原生文件的 ELF 静态对齐和隐私扫描通过。手机 APK 与 Release 按 SHA256 校验。arm64-v8a、debug 签名且可调试的 alpha，附对应源码；不发布独立测试 APK。

不改驱动、DSP、解码器、录制编码器或原用户数据。Android 16／16 KB 实机、小米 15 Pro、大字号／横屏矩阵、完整实收、长期运行及帧率验收仍待完成，范围沿用此前记录。
