# 9GRadio HF+ alpha24

`0.24.0-hfplus-alpha24` / build 25，继续基于公开源码 `002c355`，不等于官方 1.83 完整源码。

## 改动

- Tune 精调和 Step 轮改为单层 16 dp 圆角色调刻度槽与主题细轮廓。去掉整个 View 的外层底板、中央读数小框；刻度避让读数，保留刻度透视、惯性与触觉反馈。
- 快速调频 Slider 移除两端箭头，保持握柄、速度曲线、回中和立即停频。
- ETM 开始／停止／清空之间留 8 dp 间距，48 dp 触控高度。只调整布局，没有运行新扫频或清空现有电台。
- 模拟、数字及 SSTV／SAT／EiBi 使用同一 `ModeChoiceUi`，三列、12 dp 圆角、48 dp 高、8 dp 间距，共享选中与禁用色。空白末格不绘制假按钮。
- 保留 Kotlin/XML Views 与全部入口，无 Compose、驱动、DSP、解码器、录制或接收范围改动。

## 验证

构建成功，91 项现有主机测试通过。复用 3 项 Android 13 小米备用机用例，验证快调渐进速度、释放／取消／后台停频、模式和内容入口记忆、SPAN／BW 输入及 Step 调节；均通过。末次仅修改刻度槽绘制后重新构建，通过主机测试并在手机检查最终排版，不以新增镜像实现的测试代替目视核对。

实际检查 Tune、模拟模式、数字模式、SSTV／SAT／EiBi 与 ETM。ETM 按钮的可见边界间隔为 22 px，内容模式按钮间隔为 22 px；该备用机密度下约 8 dp。未触发 ETM 开始或清空动作。所有生成截图和原始日志仅留在私有构建目录，不随 Release 发布。

APK 签名、zipalign 16 KB 以及 8 个原生文件的 ELF 静态对齐检查通过；隐私扫描通过。源码和 APK 作为 arm64-v8a、debug 签名且可调试的 alpha 发布。手机 APK 与附件按 SHA256 核对；测试辅助包及生成样本在交付前清理，用户数据保留。

本轮为布局与绘制调整，不重复声称完整 RF 实收回归、Android 16／16 KB 真机或小米 15 Pro、横屏／大字号、长期运行与帧率验收。其余边界见 alpha23 记录。
