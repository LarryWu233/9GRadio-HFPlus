# 9GRadio HF+ alpha20

版本 `0.20.0-hfplus-alpha20` / code 21；公开源码 `002c355` 的独立衍生版。

## SQL 判据修复

用户报告航空 AM 频道长时间无人发话，SQL 线高于 BW 内即时峰值，仍需额外抬高约 6–10 dB 才静噪。这种持续一分钟以上的现象不能归因于 200 ms 保持。

源码核对发现：监听与录制门控取了整个 FFT 的最高峰，通带外持续信号、杂散或噪声极值也能维持开启；关闭侧还叠加固定 3 dB 滞回。不同场景偏差不一样，不将 6–10 dB 当作固定校准值。

本轮在现有 FFT 上限定当前 BW，处理 USB/LSB 方向及真实硬件中心／CW 偏移，和显示通带使用共同的宽度定义。保留 FFT bin dBFS 参考，加入约 40 ms 的线性功率 IIR 平滑；不会把频道总功率与单 bin 曲线直接混作同一个数值。

低于用户门限后保持约 200 ms 再关闭，重新开启需高出约 1 dB；保留 10 ms 音量渐变。保持时间用于防抖与保护字尾，不作为长期不静噪的修复手段。RF 页显示通带判决电平及通过／静噪状态，顶部场强也改为频道电平；宽带峰值仍单独保留为诊断字段。监听与按 SQL 门控录制使用同一判据，扫描器原有窄带平均判据不改。数字／内容解码取得监听静噪之前的音频。

## 实验性测量

RF 页“测量（实验）”采样约 3.2 秒，仅计算建议，用户选择应用或取消。参考较低时间分位电平，加上至少 3 dB 余量并向上取整。结果包含参考、波动及实际帧数，不声称能识别纯底噪；持续载波或干扰也会被测入，过高门限可能漏掉弱话音。

不自动调谐、不修改增益／AGC，也不在测量完成时自动改 SQL。只统计实际更新的 FFT 帧，缓存重放不计数。频率、BW、模式、采样率、FFT 分辨率／分析宽度／平均／平滑／窗函数、增益、接收源变化时使结果失效；断开、离开前台会取消。FFT 未覆盖完整 BW、样本不足或电平过高时不给建议。频谱分辨率会影响这种 bin 参考，改变分析条件后应重新测量。

实现与复用边界详见 [SQL 来源记录](../third-party-squelch.md)：GNU Radio 单极点 IIR 功率平滑、Gqrx 自动 SQL 的 +3 dB 余量；没有照搬旧 SDR++ 平均幅度的量纲，也没有自行新增语音识别或神经降噪。

## 验证

- 88 项主机测试通过，新增 8 项涵盖带外抑制、门限上方 0.5 dB 关闭、65 秒等效静噪、USB/LSB 与 CW 中心偏移、线性功率平均、缓存帧与配置切换、建议统计与无效数据、字间保持。旧话音保持测试改为真正回到门限上方后复位计时，符合新的门限语义。
- Android 13 小米备用机完成 5 项针对性检查。
- IQ 链路 2 项：240 kS/s、2048 点 FFT、AM／10 kHz BW，带外持续强载波约 −20 dBFS；通带弱 AM 低于 −65 dBFS 门限时连续观察 65 秒，记录到的误开启为 0。另验证通带信号增强后开启、门限高于观察到的通带峰值 0.7 dB 后关闭，以及 SQL 关闭时解码入口仍持续收到 PCM。
- 测量 UI 1 项：已知噪声与强带外载波的浮点 IQ 文件回放，验证显示建议前后 SQL 不变、取消、应用、改变 BW 取消、离开前台取消；核对实际暗色弹窗排版。该样本不是现场航空录音。
- FM 原生连续性和立体声路径 2 项通过。
- APK 签名、zip 对齐与全部 8 个原生文件的 ELF 16 KB 静态检查；本轮未改原生算法或增加原生库。

这些结果证明已知 IQ 条件与界面行为，不等于完成用户现场航空频道复测。Android 16、16 KB 真机、长期性能验收和 EiBi 在线刷新等此前边界保持原记录。APK、源码与校验值随 Release 提供；设备日志、截图、原始样本和本机路径只留本地构建目录。
