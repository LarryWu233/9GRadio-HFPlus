# alpha4：FM 链路、频谱调谐与 ETM 检测修复

版本 `0.4.0-hfplus-alpha4` / 5，包名 `com.radiosport.ninegradio.hfplus`。
仍基于公开源码 `002c355`，保留 alpha3 的 HF+ 接入、菜单模块与地图等改动。

## 音频与带宽

确认并修复两处具体缺陷：

1. `FM` 的默认带宽是 200 kHz，但工厂映射到 `NfmDemodulator`，DSP 又把它视为窄带模式。
   现在 FM/WFM 都进入广播 FM 中频和解调链路；NFM 保持独立窄带链路。
2. 多相重采样器把原型滤波器按输入采样率设计，而非插值后的采样率，并在输出时刻使用错误的历史输入位置。
   重新实现有状态 upfirdn，跨任意块保留输入/输出时钟、相位和滤波历史。

FM/WFM 的带宽原先只影响 UI，固定 WFM 预抽取滤波器忽略该值。
现在选定宽度控制复数低通的实际截止频率，中频采样率保持稳定，避免把窄滤波宽度误当成解调采样率。
滑条提供 50/75/100/125/150/175/200/225/250 kHz 档位，并根据当前中频能力限制上限。
过窄的广播 FM 通带会损伤声音，可按“自动”恢复。
旧模式快照中低于广播 FM 最低宽度的值按自动处理。

增加运行诊断：HF+ IQ 块序号缺口、原生驱动丢失样本、PCM 队列丢块、AudioTrack 欠载次数，
用于重连后区分重采样、USB 吞吐与播放供给不足。
这些代码修复不能证明本次用户听到的所有断点均已消失；仍需实收复核。

## 调谐与频谱

| 操作 | alpha4 行为 |
| --- | --- |
| 频段条右侧小键 | 切换“拖动调谐 / 点选居中”，两张图共用同一模式 |
| 拖动调谐 | 左右拖动频谱或瀑布，频率随拖动变化，选中频率保持居中；按当前步进对齐 |
| 点选居中 | 点击任意频率将其调到中央；拖动不触发调谐，减少误操作 |
| Tune 回中滑条 | 左右偏移控制调谐速度，中心死区，距离越远加速越快，松手/失焦/隐藏停止并回中 |
| 震动 | 图表调谐和滑条调谐按系统触感设置反馈，最多约每 45 ms 一次 |
| 顶部数字 | GHz/MHz/kHz/Hz 分组底色，MHz 高亮、Hz 缩小弱化；全部数位仍可选择 |
| 普通步进 | 默认至少 1 kHz；按所选步进对齐，通常 Hz 三位为 000。12.5 kHz 等特殊步进、显式细调或手动输入保留所需精度 |

移除频谱/瀑布在多次调谐后累计的“分数 FFT bin 偏移”；坐标转换以实际拨盘频率与硬件中频偏移为准。
新增待执行的界面断言，检查任意非整 bin 频率变更后两图中心仍等于拨盘频率。

频率与模式分开管理。切换解调不再回放旧 RF/显示快照或旧模式频率，重启也不读取旧模式频率键。
开启自动解调时，频率驱动常用模式建议；关闭后可在设备支持范围内任意频率使用所选解调。
设备本身不支持的频率与解码所需硬件条件仍受能力限制。

## 瀑布与面板

点击频谱/瀑布分隔条打开 Min / Max 两个滑条：Min 调整暗背景下限，Max 调整亮信号上限，
同时保留自动电平、原有配色和布局入口。只影响显示，不改变 RF 增益和音量。
保存原始历史电平以重新着色已有历史，不仅改变之后到来的新行；重着色合并到绘制时，最多约每 80 ms 更新一次。
正常接收继续使用 32 行纹理分块。

底部设置面板采用固定展开/收起两档，禁用容器自由拖动；把手点击或上下划动切换，点击模块图标展开。
内部滚动不再拉动整个面板。展开高度不再随瀑布高度反复变化。

状态栏透明、深色工具栏背景延伸到状态栏和刘海 inset；保留底部导航区安全距离。
全面屏与 Android 16 的实际显示仍需真机检查。

## ETM

通用扫描器保留原检测方式。仅 ETM 启用广播专用检测器：

- SW：局部噪声参考、载波突出度、相邻 FFT bin 支持，排除单 bin 尖峰和 DC 区域。
- FM：按频道积分并检查一定宽度的占用比例，窄尖峰不能冒充宽带 FM。
- 两次独立采样确认，增加到 100 ms 的调谐等待并清除旧频率 FFT 平均。
- 增加覆盖重叠，按频率距离合并同一候选，提供 10–24 dB 的确认阈值。
- 清除旧检测器生成的 ETM 暂存表，不改收藏；结束后恢复原频率、模式及自动解调开关。

这是广播候选检测，不具有台名识别或所有干扰分类能力。20 组确定性噪声样本无误检，
孤立强尖峰、整片高电平噪声被拒绝；受支持的模拟 AM 载波和宽带 FM 区域通过。
这不等于实际接收环境下零误检，仍需 HF+ 实扫调校。
