# alpha3：设备界面、调谐、降噪、ETM 与地区推荐

版本：`0.3.0-hfplus-alpha3` / 4。基线仍是公开源码 `002c355`，不是官方 1.83 的完整源码。
包名 `com.radiosport.ninegradio.hfplus`，可与官方版并存。

## 使用入口与行为

| 入口 | 行为 |
| --- | --- |
| 顶部频率 | 十个数位覆盖 1 Hz 至 GHz 位；点选数位后上下拖动，长按输入。程序刷新不再重复发送调谐命令 |
| 顶部加减键 | 使用当前步进，长按连续调谐。支持 HF+ 的 500 Hz 下限与两个有效频段边界 |
| 调谐图标 | 步进、更多步进、滤波实际数值、收窄/自动/放宽、频段预设、自动解调、ETM、地区推荐 |
| 天线图标 | 适合当前接收机的控制及监听音频；HF+ 为输入衰减和 HF AGC，隐藏偏置供电、RTL 数字 AGC、RTL 直采 |
| OPEN/CLOSED | 启停接收源；CLOSED 停止 IQ、音频和 DSP，释放 USB 与原生解码器。再次 OPEN 新建连接并恢复有效参数 |
| 频谱/瀑布分隔条 | 拖动调整比例，点击选择清晰/弱信号配色与布局预设。调整高度保留历史 |
| 设置 → 菜单模块 | 调整六个基础页面的顺序、显示或隐藏；设置入口保留，启动进入第一个可见页面 |

**CLOSED 的语义按用户最新要求改为接收机启停。** alpha2 的“只静音并继续接收”已被替换。

频段标签覆盖 HAM、短波、中波、FM、航空通话/导航及一般频段。
自动解调默认关闭；开启后按频段建议选择常用模式，手动选模式退出自动。
切换模式保留当前频率、硬件增益/衰减、采样率、音量和降噪开关；必要时提升采样率以满足模式带宽。
滤波、FFT 等模式参数可分别恢复；用户选定的配色和显示偏好不再被旧模式快照覆盖。

旧版“默认硬件参数”在设置页与实时控件重复、状态不一致，因此统一使用主界面的实际控制。
清理没有后端效果的 Out-of-bound 界面开关；统一由接收源能力校验频率。

## ETM

复用已有宽带 FFT 扫描器，新增单次完成选项。
短波范围 2.3–26.1 MHz，FM 范围 87.5–108 MHz，按设备覆盖范围取交集。
短波和 FM 暂存表彼此独立，最多 512 个候选结果；采用回收列表，不写入收藏数据库。
扫描时静音监听，完成或停止后恢复原来的模式和频率，点候选项后调谐。
退出界面、关闭接收机或应用离开前台会结束扫描。录制期间不启动 ETM。

这是候选信号搜寻，不以频谱峰值冒充已确认的广播台名称。搜台质量仍需不同接收环境下实收复核。

## 地区与附近机场

内置中国、北美、欧洲、日本、澳大利亚、新西兰的常用 APRS 建议及手动选择。
GPS/网络定位使用 Android 运行时授权，支持近似位置；拒绝授权或暂时无定位时可手动选择地区。
取得位置后在设备内计算 200 km 范围内的附近机场，并列出塔台、进近、ATIS 等已收录通信频道。

内置 OurAirports 数据：10,708 个有通信频率的机场、27,009 条频道，其中中国机场 57 个。
下载日期为 2026-11-06；CSV 来源、下载时间、SHA-256 在
`app/src/main/assets/receiving/sources.json`。这是社区参考数据，覆盖与准确性不等同于官方航空资料。

位置自动应用单独设置，默认关闭。开启后在明确进入 APRS、ADS-B 或航空 AM 时使用建议；
定位返回时核对用户是否仍在原模式和频率，避免覆盖之后的手动调谐。
1090 MHz ADS-B 不按地区改频，HF+ 下继续不可用；ACARS 提供常用候选而不伪造本地专用频道。

数据和规则来源：

- [OurAirports 开放数据与 Public Domain 许可](https://ourairports.com/data/)
- [IARU Region 3 频段计划](https://www.iaru-r3.org/wp-content/uploads/2025/01/R3-004-Band-Plans-IARU-Region-3.pdf)
- [IARU Region 3 APRS 地区频率记录](https://iaru-r3.org/17r3c/docs/d-16m_rev.pdf)
- [APRS 原始项目资料](https://www.aprs.org/)
- [FAA ADS-B 安装资料](https://www.faa.gov/air_traffic/technology/equipadsb/installation)
- [FAA 航空 VHF 频段资料](https://www.faa.gov/airports/resources/advisory_circulars/index.cfm/go/document.information/documentNumber/90-50D)

## 降噪

保留连续分帧和重叠相加，加入决策反馈、时间/频率平滑及更温和的幅度增益。
噪声估计与状态重置在 DSP 消费线程内处理，启停使用对齐的干/湿信号交叉淡化。
默认 48 kHz 处理的固定延迟为 1024 个样本，约 21.3 ms；关闭 NR 时不计算频谱降噪。
原始解码链路不使用降噪结果。

本机合成语音加固定白噪/彩噪、匹配语音电平后的基准：

- 输入 SDR −2.51 dB，输出 −0.43 dB，改善约 2.08 dB。
- 未匹配前语音幅度比约 0.63；比较 WAV 已按语音电平匹配。
- 同时检查稳定噪声残留波动及启停间隙、突变。

这只是该受控样本的测量，不能证明所有实收语音的主观质量。
样本和指标：`build/audit/nr-fixtures/before-level-matched.wav`、
`after-level-matched.wav`、`quality.json`。

## 验证范围

当前真机：小米 M2007J1SC、Android 13、arm64、4 KB 页，通过无线 ADB 调试。

- 15 项单元测试通过，包括 FFT、NR/NB、启停淡化、噪声均匀性、语音对比、频段和地区规则。
- 真机验证涵盖 USB 实际关闭/重开、连续快速启停、单次扫描结束、控件隐藏和恢复、
  瀑布历史保留、Hz 级调谐、离线机场数据及模块位置映射。
- 主界面集成测试涵盖自动模式、频率保持、硬件状态保持、显示偏好保持、菜单排序和隐藏。
- 实机分别完成 SW、FM 全范围单次 ETM，得到 78、81 个候选频率；扫描日志确认恢复原来的
  99.088468 MHz / AM。候选数量只表示该次环境的检测结果，不表示已确认的广播台数量。
- 修复重开时采样率仍显示 0、扫频末尾预览覆盖恢复后的显示；SSB 恢复使用用户拨盘频率，
  避免把硬件 BFO 偏移叠加到恢复值。
- 最终 APK 的六个原生库 LOAD 段均按 16 KB 对齐，APK 通过 `zipalign -c -P 16 4`。
- 详细输出保存在 `build/audit/alpha3-*.txt` 与 `alpha3-*.log`；失败尝试不作为通过结果。

### 60 秒调谐与瀑布上传优化

同一备用机、HF+ 接收开启、相同页面及配色，两次各执行 199 个上下交替的 Hz 位拖动。
使用 `scripts/profile_tuning.py`，通过 Android `dumpsys gfxinfo` 记录渲染耗时：

| 指标 | 整张历史纹理更新 | 32 行分块更新 |
| --- | ---: | ---: |
| 渲染帧数 | 2509 | 2502 |
| Android deadline 慢帧 | 14.95% | 5.28% |
| P95 / P99 | 19 / 22 ms | 16 / 20 ms |
| 慢纹理上传次数 | 362 | 2 |
| ≥101 ms 耗时直方图区间 | 0 | 0 |

分块仍保留 1024 行历史、相同时间刻度和缩放；每次仅更改所在分块。
这是本轮修改前后的对比，并非原版 APK 对比；2502 个实际重绘帧不等于持续 60 fps。
**5.28% 仍未达到低于 5% 的验收目标**，高刷新率及不同页面布局仍待测。
测试过程中手机电量较低，未更改系统刷新率或开启省电模式。

分块版已安装并完成上述性能测试。新增的历史跨分块/环形回绕断言已编译；
准备重新执行界面仪器测试时无线 ADB 掉线，最终这轮重跑没有执行成功。
此前 6 项设备仪器测试、1 项主界面集成测试和 1 项基线链路测试分别通过，
不将它们冒充最终分块实现的全部回归结果。
