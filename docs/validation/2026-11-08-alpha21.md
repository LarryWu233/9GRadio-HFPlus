# 9GRadio HF+ alpha21

版本 `0.21.0-hfplus-alpha21` / code 22；延续公开源码 `002c355`（应用配置 1.39）的独立衍生版，不是官方 1.83 完整实现。

## 界面

- 固定版本 BlurView 的模糊背景覆盖整个控制菜单，控件与文字保持清晰，叠加当前主题的暗色透明层。没有重写模糊算法。
- 箭头合入菜单顶栏的独立 24 dp 行，图标行 44 dp，收起高度按实际顶栏加导航栏 inset 计算；收起后正文隐藏，避免不同导航布局露出正文。
- Tune 滚轮绘图及淡出边缘按圆角路径裁剪；弹窗、播放器卡片和录音行统一圆角。原有模式表格不改成大量胶囊按钮。
- 撤下瀑布图上两个悬浮按钮；收藏仍从设置进入，扫描仍在扫描模块，旧数据保留。

## 录制与播放

- 设置 → 录制文件：默认 M4A/AAC 128 kb/s，另提供设备支持的 OGG/Opus 和 WAV。压缩格式选择目标码率，WAV 选择 16／24-bit PCM 或 32-bit float；参数用于下一次录制。Opus 编码为 48 kHz，需要时复用已有分声道重采样。
- 编码由 Android MediaCodec／MediaMuxer 在有界队列的专用线程完成，不在 AudioTrack 写入线程执行。跟不上时报告错误并停止录制，不将丢块隐藏为成功。WAV 仍受 RIFF 约 4 GB 上限约束。AAC／Opus 为有损格式，后续弱信号解码建议 WAV。
- 保留自动停止、SQL 门控、IQ 原始格式与既有回放；声音元数据按实际输入帧计时，压缩容器结束后更新文件大小。
- 每条录制显示时长；旧记录缺少元数据时后台读取声音容器或根据未压缩 IQ 的格式／速率计算。无法确定的时长显示占位，不编造数值。
- 声音回放复用固定版本 Media3 1.7.1：暂停、拖动进度、短按前后 10 秒、长按连续快进／快退、停止恢复监听。录音页可展开到主频率数字下方，仍在原菜单中。
- 回放暂停期间也保持实时监听静音，停止／播放结束恢复；仅控制扬声器输出，不暂停接收、解码和录制，不改保存的监听音量。IQ 没有新增暂停或随机定位。

实现和许可边界见 [录制／播放来源](../third-party-recording-playback.md)与 [BlurView 来源](../third-party-blurview.md)。

## 验证结果

JDK 17／Gradle 8.13／AGP 8.13.2／Kotlin 2.2.0／SDK 35／NDK r28c 固定构建通过，91 项主机测试通过。新增 3 项验证 24-bit 符号及奇数字节填充、float WAV 头和样本、录制配置默认值与旧 WAV API。

Android 13 小米备用机、arm64、4 KB 页上通过 14 项针对性自动检查：

| 检查 | 数量 | 实际覆盖 |
| --- | --- | --- |
| 压缩编解码往返 | 3 | AAC／Opus 48 kHz 双声道、44.1 → 48 kHz Opus；四秒样本容器时长误差小于 150 ms、实际解码帧数、声道隔离、文件小于对应 PCM 的三分之一。 |
| Media3 与面板 | 2 | 五种输出配置实际播放及定位；列表时长、暂停、拖动、长按快进、展开位置、停止；收起正文隐藏、箭头不压图标、FAB 移除、全层模糊及 0／24／48 dp 导航 inset 分发。 |
| 压缩录制集成 | 1 | 已知 AM IQ 文件，SQL 关闭不录、开启后录制；仅扬声器静音时录制帧继续增加；自动停止完成 M4A，数据库时长与容器误差小于 150 ms，接收继续。 |
| 既有录制与主题 | 2 | IQ／WAV 门控及定时停止、二级设置不重建 DSP；七套暗色主题、文字对比度及正常单选框。 |
| Tune、地图与顶栏 | 3 | SPAN/BW 长按输入、Step；实际地图拖动／双指缩放不带动菜单；图标点击与箭头收起。 |
| 模式记忆 | 1 | 开关冻结／恢复、内容页与常用解调选择、重建保留状态。测试在初始模式保存后建立自己的 FM 历史，避免依赖用户原来的电台。 |
| FM | 2 | 原生 FM／WFM 连续性与立体声独立声道输出。 |

另外从手机实际设置入口打开录制文件页面和格式选择框，核对 AAC／Opus／WAV 选项、暗色背景与圆角，未改变用户录制参数。录音页正常与展开排版已核对。测试曾遇到 MIUI 连续 Activity 场景启动超时，改用每项独立显式桌面入口重测通过；不将超时记录计作通过。新增压缩录制测试也修正了初始化配置覆盖测试门限的竞态，先等待界面初始化，再通过 ViewModel 设置门限并确认门控关闭。

全部 8 个原生文件通过 ELF 16 KB 静态对齐检查，APK 签名与 zip 对齐通过。本轮没有新增原生库。

## 边界与清理

本轮通过已知 PCM／IQ 验证，未将其写成新一次 HF+／RTL 现场接收验收。当前备用机不是小米 15 Pro；该机真实显示配置、Android 16、16 KB 运行设备、旧 Android 兼容、长期录制／存储压力、60 秒帧率及 30 分钟持续接收目标仍待验收。不同设备的硬件编码器也需分别验证。EiBi 网络刷新等先前记录的限制不变。

测试记录只删除本轮自己创建的文件与数据库行，保留用户原有录音与接收参数；测试 APK、原始日志、截图及样本不进入 Release。源码保留可复现测试，发布物单独检查私密路径、凭据与配置，源码压缩包保留 LF 格式 Gradle 启动脚本。
