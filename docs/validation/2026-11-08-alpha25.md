# 9GRadio HF+ alpha25

`0.25.0-hfplus-alpha25` / build 26，继续基于公开源码 `002c355`（应用配置 1.39），不等于官方 1.83 完整源码。

## 改动

- AppBarLayout 关闭 lift-on-scroll 及其颜色动画；固定状态栏 inset 与工具栏为 `radioSurface`，保持透明系统栏、edge-to-edge 和原 inset 高度。
- 共享分段选择器在加入 MaterialButtonToggleGroup 前设置 `RelativeCornerSize(0.5f)`，保持真正半圆的外端圆角；不再让 44 dp 高的控件沿用 24 dp 固定圆角。取消子按钮装饰投影，分段选择行为保留。
- 移除面板顶部额外 12 dp 渐变 View。BlurView 半径仍为 12，色调遮罩 alpha 从 184/255 降至 171/255，不透明度约 72.2% → 67.1%，增加背景透出约 5.1 个百分点。
- 不改接收、DSP、解码、录制、调谐、地图或设置存储链路。

## 验证

构建成功，91 项既有主机测试通过；本轮没有为可逆的绘制调整新增镜像测试，也不把旧版完整真机检查计入本轮。

在 Android 13 小米备用机、当前碳蓝主题复现：修复前，状态栏空白采样区 RGB 在滚动时由 (22,27,34) 变为 (29,38,48)。修复后，同一区域滚动前、滚动后及控制面板收起时均为 (22,27,34)，逐像素 RGB 平均绝对差均为 0。比较避开时钟、图标和通知内容，结果针对该区域及当前配置。

实际检查 ETM／范围扫描、SW／FM、显示范围“频谱／瀑布图”分段外端，圆角连续且无原来的微小折线；ETM 选择 FM 后恢复 SW，没有开始扫频或清空电台。核对面板箭头上方不再有额外亮色渐变，模糊前景控件保持清晰。截图、日志和像素比较仅保留在私有构建目录。

APK 签名、zipalign 16 KB、8 个原生文件的 ELF 静态对齐及隐私检查通过。手机安装 APK 与 Release 按 SHA256 校验；原用户数据与设置保留。发布 arm64-v8a、debug 签名且可调试的 alpha APK 及对应源码。

本轮未重新进行完整 RF 实收、七主题与大字号／横屏矩阵、Android 16／16 KB 实机、小米 15 Pro、帧率或长期运行验收。其余边界沿用 alpha24、alpha23 记录。
