# 9GRadio HF+ alpha14 验证记录

公开基线 `002c355`；版本 `0.14.0-hfplus-alpha14` / code 15；独立包名不变。当前设备是小米 M2007J1SC、Android 13、4 KB 页，RTL-SDR Blog V4 经 OTG 连接。天线为用户提供的 YouLoop；用户明确说明其 1 GHz 接收能力有限，不以本次目标数量评价 1090 MHz 极限接收性能。官方 1.83 单独安装并保留。

## ADS-B 接收修复

公开代码原先以 1.920 MS/s 接收，而旧 Kotlin 检测器按 2 MS/s 判断脉冲，并有跨块与定位处理缺陷。本次改用官方 readsb 固定版本的原始解调与跟踪内核，统一 2.400 MS/s UC8 输入。原始 IQ 不经过监听降噪、静噪和音频处理。解码器归接收服务所有，地图／雷达切换不重启它；CLOSED 停止 native 进程和 USB 输入，OPEN 新建接收会话。

首次进入 ADS-B 使用独立射频配置：手动 44.5 dB、关闭两种 AGC，之后记忆用户对此模式的调整。退出 ADS-B 恢复模拟模式参数，不覆盖模拟收听设置。进入 ADS-B 默认显示完整 2.4 MHz；显示缩放按设备与模式分别保存。

官方 1.83 在本机的观察值也是 2.400 MS/s、手动 44.5 dB，曾看到 ICAO `70AA79`。改造版 60 秒实收记录取得 ICAO `7821CE`，4 条有效报文、1 个目标，未取得位置报文。两次观察时间不同，不能作为接收率的等条件对比，也不构成真实飞机地图定位验收。

## 交互与外观

- ADS-B 默认地图，开关在同一模块切换地图／雷达；APRS 在模块内开关地图。展开按钮将整个控制面板上拉到顶部频率数字下方，保留主界面，不跳转。按钮还原、把手下拉和返回键可退出展开。
- 飞机列表保留高度、速度、坐标及点击详情。距离使用 Android WGS84 计算；“最大距离”为当前目标中的最远距离，“记录距离”为该接收位置下的历史最远值，可点击清除。没有接收位置或目标坐标时显示“—”。
- APRS 默认点击详情；保留自动弹窗开关。地图位置保留十分钟，地图与协议筛选使用同一数据源。
- 地图默认采用原版 APK 的 OSM 栅格地址，保留署名和缓存；MapLibre OpenGL 负责绘制。不注册账户、不批量下载公共瓦片。接收位置可手填或调用 Android 定位。
- 测向仪恢复指南针呈现，手机磁北朝向来自 Android 方向传感器；输入电平来自真实 IQ。没有伪造无线电信号方位或测向站。
- 背景采用近黑蓝；开关开启橙色、关闭灰色；滑条为低饱和蓝绿色。原有频谱十种主题和瀑布十一种配色保留。

## 验证范围

最终构建通过，46 项主机单元测试通过。同一最终 APK 已通过 22 项 Android 检查：10 项样本／配置／绘制检查，9 项显示、手势、降噪控制、统一控件、面板展开和地图样本检查，以及 3 项真实 RTL 连接、启停／视图切换和一分钟实收检查。包括 readsb 输入到输出、2.4 MS/s 与独立增益恢复、距离记录、模式频率记忆及原有接收机控件绘制。

全部 7 个原生库 ELF 16 KB 对齐及 APK `zipalign -c -P 16 4` 静态检查通过。原有五个非地图原生库与 alpha13 APK 字节一致；本轮增加 readsb，MapLibre 改用同版本 OpenGL 包。解调／CRC／CPR／跟踪五个上游核心文件与固定提交归档逐字节一致。

用户解锁后，已检查真实屏幕截图：地图／雷达在同一模块切换；展开后的面板顶部位于频率数字底部（误差不超过 4 px）；还原后恢复普通高度；指南针显示实际传感器朝向。`DigitalPanelUiTest` 通过。

`MapSceneTest` 在实际模块内验证 ADS-B 与 APRS 各一个明确标为样本的 WGS84 位置，两类图层都渲染成功且协议筛选正确；五分钟前的 APRS 位置仍保留。截图显示目标标记，**不是实收飞机定位证据**。手机从应用内直接请求原版 OSM 瓦片返回 `SocketTimeoutException`；在线底图仍未通过，不宣称空白底图已修好，不改手机网络配置或擅自更换地图源。

旧光标测试在 2.4 MHz 显示宽度下遇到归一化 Float 坐标往返的 1 Hz 舍入差异，现允许 1 Hz 差异；查看期间不调频、不改带宽的精确检查仍保留并通过。地图测试改为在同一主界面的实际模块中验证，避免辅助 Activity 切换受小米后台启动限制的影响。

解锁后先完成 USB 连接电脑时的界面验证；接回 RTL-SDR Blog V4 后，`MainInteractionTest` 和 `DigitalReceiverLifecycleTest` 均通过。地图／雷达切换和面板展开期间 IQ 继续输入；CLOSED 后 source 为 null、native 解码器停止、目标清空；OPEN 后新会话恢复到 2.4 MS/s。首次未接接收机时等待连接超时，未通过放宽断言解决，接回设备后重新运行通过。

最终 APK 一分钟实收检查通过：59.1 秒日志中累计 12 条有效报文，1 个真实目标 `7806A9`，139,714,560 个 IQ 样本进入 readsb；本窗口没有定位报文。`alpha14-final-live.jsonl` 和汇总随交付保留。结合 YouLoop 的接收条件，不能据此认定解码器定位异常，也不能宣称完成了真实飞机位置和距离的验收。

样本与配置回归前后的接收机、显示、模块及地图设置已按文件字节恢复；私有备份不进入交付包。

已有底层证据：readsb 上游 CPR 80 项检查通过；90 帧已知 UC8 样本全部被 native 解码，覆盖 CRC、呼号和高度。重复的定位帧不满足真实运动约束，未为样本放宽 readsb 生产定位过滤。

## 尚未完成

- 原版完整 RDF 的测向站联网／融合／无线电方位算法不在公开源码中；当前是指南针和真实接收电平，不是完整 RDF 恢复。
- AIS 解码实现仍缺失，不列为已恢复。
- 实收飞机位置、定位按钮实际取得 GPS/网络坐标、Android 16、16 KB 页运行环境、60 fps 指标和连续三十分钟验收尚不能据本轮结果宣称通过。
- 在线底图受当前手机网络可达性影响，目标解码与离线数据不依赖底图请求成功。
