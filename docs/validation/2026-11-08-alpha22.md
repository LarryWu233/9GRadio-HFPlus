# 9GRadio HF+ alpha22

版本 `0.22.0-hfplus-alpha22` / code 23，延续公开源码 `002c355` 的衍生版。

- 展开／还原按钮移到“录制”标题行右侧，播放器文件名独占一行，避免操作入口被文件名或下方内容挤压。
- 播放／暂停、快进／快退、停止采用透明的独立图标，取消原来的彩色圆角底框；仅保留按压时的无边界水波反馈。
- 没有修改编码器、DSP、SQL、录制参数或 IQ 回放。

构建及 91 项主机测试通过；Android 13 小米备用机完成既有录音播放器／面板检查 1 项，覆盖录音列表时长、暂停、进度拖动、长按快进、展开／还原及收起边界，并核对实际排版。alpha21 的五种声音格式及其他回归结果保留在[上一轮记录](2026-11-08-alpha21.md)，本轮不声称重做完整硬件验收。

APK 签名、zip 对齐及 8 个原生文件的静态 16 KB 对齐检查通过。测试样本和独立测试包不随 Release 发布，原有录音与接收参数保留；小米 15 Pro、Android 16、16 KB 实机和长期性能仍按先前边界待验收。
