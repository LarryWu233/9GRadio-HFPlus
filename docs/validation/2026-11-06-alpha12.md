# alpha12：解调前脉冲抑制与模拟/数字模式旁路

版本 `0.12.0-hfplus-alpha12`，versionCode 13，基于公开源码 `002c355` 的衍生测试版。包名 `com.radiosport.ninegradio.hfplus`，已更新到小米 M2007J1SC、Android 13；本次 APK 为 arm64-v8a。

## 接收链路

- NB 从解调后音频移到通道抽取、滤波和解调之前的宽带 IQ 缓冲。不再对单声道或左右音频做第二次 NB 置零。
- AM、USB、LSB、DSB 直接使用 WDSP 2.11 的插值式 NB2 内核，处理短脉冲及前后过渡。
- FM、WFM、WFM Stereo、NFM 使用 SDR++ 的 IQ 幅度脉冲抑制，同一个正增益作用于 I/Q，保留相位，不插值或移动采样位置。
- 原始 IQ 录音、FFT/瀑布和原始数据消费者先取分支；新 NB 只修改 DSP 自己的复制缓冲。原始 Float32、Unsigned8 输入和录音不因 NB 开关改变。
- NR、陷波、响度补偿仍在解调后的监听音频端。数字模式以及 CW/CWR/RAW 立即旁路 NB、NR、陷波和响度补偿，包括已解码数字语音输出；界面关闭并禁用这些选项。回到模拟语音模式恢复保存的设置。
- SW、MW 属于频段，开关按当前解调模式判断。普通静噪与音量继续只控制监听，不删除数字解码数据。
- 未接入神经网络模型或运行时。

来源、固定提交、许可、参数及接入边界见[复用记录](../third-party-reuse.md)。WDSP `xnob` 内核与作者发布版相同，没有另写脉冲检测或插值修复算法。

## 控制及延迟

接收机与音频页的 NB 现在明确标为“解调前脉冲抑制”，提供 3～20 倍背景幅度的检测门限，默认 8 倍。首次使用默认开启 NB，已有手动开关选择保留；门限越低越敏感。

AM/SSB 分支使用相同的干路延迟和 2 ms 混合过渡，避免开关改变采样时序；912 kS/s 时延迟 2061 个复数样本，约 2.26 ms。FM 分支无前瞻延迟，开关过渡只改变幅度。模式、频率或采样率变化清理旧历史；释放接收机时销毁处理实例。

## 样本验证

| 场景 | 结果 |
|---|---|
| 912 kS/s IQ：已知 AM 信号叠加约 49 μs、50 Hz 重复脉冲 | 相对干净参考的 IQ 均方误差下降 35.74 dB；729600 个复数输入对应相同数量输出，干预 6504 个样本 |
| 干净 AM、开关交替、不同块边界 | 扣除固定延迟后幅度和相位保持一致，无干净样本误修复 |
| 228/912/3200 kS/s 及连续速率切换 | 输出长度、状态和分块连续性通过 |
| 超过设定修复时长的干扰、重新调谐 | 输出有限值，持续干扰后恢复，旧频率数据不泄漏 |
| FM 幅度脉冲 | I/Q 相位误差在浮点容差内，脉冲幅度受到抑制 |
| 全部非语音模式：先开模拟处理，再切换 | IQ 及监听样本立即原样通过，包括首块，无遗留降噪过渡 |

完整链路以同一组合成 IQ 分别运行 NB 开/关，经实际通道滤波、解调、重采样、播放和 WAV 录制比较。原始 IQ 录音逐字节核对：

| 输入与模式 | 归一化音频残差变化 | 原始 IQ 录音 |
|---|---:|---|
| Float32、AM、228 kS/s | −6.69 dB | 相同 |
| Unsigned8、AM、228 kS/s | −6.61 dB | 相同 |
| Float32、WFM、228 kS/s | −0.09 dB | 相同 |
| Float32、WFM、912 kS/s，包含通道抽取 | −0.48 dB | 相同 |

音频指标在完整的 20 ms 窗内分别拟合直流与 900 Hz 正弦，计算其余能量相对于去直流信号能量的比例，排除原有 AM 直流及缓慢增益变化。以上是指定合成脉冲的结果，不等同于所有环境中的降噪量或人声可懂度。

研发对照发现，将相同 WDSP 插值参数直接用于广播 FM 会增加相位杂声，因此最终版对 FM/NFM 选择 SDR++ 保相位幅度处理。最终方案在两种采样率下均未加重这个样本的音频残差；不宣称 FM 的改善量与 AM 相同。早期对照日志与最终回归记录分开保存。
