# 实现与依赖约定

用户要求：涉及底层设计，先查阅成熟项目，优先复用优质现成内容，不直接另写一套。

- 驱动、音频后端、重采样、FFT、滤波和解码等基础组件，新增或替换前先记录参考源码、固定版本、许可证、适用条件及验证方式。
- 优先使用兼容许可证的维护中组件；Android 优先检查平台官方音频方案及其已验证实现。
- 只编写接入、状态同步和界面所需的适配代码。不能把“参考过”当成已复用，也不能仅增加缓存就声称解决所有实收断音。
- 实收问题先区分 IQ 丢样、PCM 丢包、播放欠载、静噪门限及音频时钟，保留可核对的诊断记录。
- 原版已有且表现良好的显示与交互优先保留；需要改变时明确问题与收益。
- UI 协议缩写、单位及 Step/BW 等常用术语可保留英文；声音、频谱、瀑布和详细设置使用中文。
